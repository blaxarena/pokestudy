# 숲속 독립 그래픽 에셋

첫 번째 숲속 그림의 색감·선·빛 방향을 기준으로 새로 제작했습니다. 두 번째 시안은 자산 분류 참고용입니다.

구성: 배경 1장, 나무 5종, 다리·통나무·그루터기 각 1종, 버섯 2종, 바위 3종, 풀 6종, 꽃 6종, 수풀 5종, 기타 식물 5종. 총 36파일.

개별 오브젝트는 별도 투명 PNG입니다. 배경에는 먼 숲과 지형·물길·오솔길만 남기며, 가까운 가림 오브젝트는 따로 배치합니다. 기존 그림에서 합성 패치를 오려내지 않습니다. 이 패키지를 기존 플레이 장면에 자동 적용하지 않습니다.

실제 해상도/알파 검사 결과는 manifest.json에 기록했습니다. PNG의 투명 테두리를 포함한 전체 캔버스 크기와 보이는 오브젝트 크기는 서로 다릅니다.

## 확인 및 다운로드

- 웹 갤러리: https://blaxarena.github.io/pokestudy/asset-packages/forest-01/
- 전체 ZIP: https://github.com/blaxarena/pokestudy/raw/refs/heads/main/asset-packages/forest-01.zip
- PNG 파일 이름을 누르면 개별 원본을 열 수 있습니다.
- ZIP을 풀면 PNG 파일을 바로 열어 사용할 수 있습니다. `index.html` 갤러리는 JSON을 읽으므로 웹 주소로 확인하세요.

## 배경과 좌표

원경의 숲과 연속된 지면·물길·흙길은 배경에 포함됩니다. 배치할 가까운 나무, 바위, 소품과 식물은 별도 파일입니다. 배경 위에 독립 오브젝트를 추가하거나 제거해도 배경 자체에 빈 구멍이 생기지 않습니다. 첫 그림을 그대로 잘라 원래 위치를 복원하는 방식이 아니라, 같은 화풍으로 새로 제작한 세트입니다.

모든 파일은 투명 여백을 포함해 1672×941px입니다. 따라서 각 오브젝트가 그림 전체를 채우지는 않습니다. `manifest.json`의 visibleBounds는 알파 값 10 초과 픽셀의 바운딩 박스이며, anchor는 그 영역의 아래쪽 중심을 정규화한 권장 배치 기준점입니다. 기존 게임의 장면 좌표와는 별개입니다.

## 검수 범위

이미지 크기, 알파 범위, 투명 픽셀 비율, 모서리·테두리 알파, PNG 디코딩을 검사합니다. 검은색/어두운색 바탕에서 시각 확인하고, 흰색·분홍색·체크무늬로 바꿔 볼 수 있는 갤러리를 제공합니다. 재작업에서 큰 배경 잔여물과 떨어진 조각을 제거했습니다. 생성된 그림은 용도별 최종 배치 크기에서 추가 미술 검수를 권장합니다. 현재 게임에 적용하거나 전체 장면의 가림 비율을 검증한 결과는 아닙니다.
