# 바다 1장 — 모래사장과 얕은 바다

숲속과 같은 밝은 동화책·컬러펜슬 화풍을 기준으로 제작한 별도 그래픽 에셋 세트입니다.
기본 배경 1장과 독립 투명 PNG 에셋 15개로 구성합니다. 각 파일의 캔버스는 1672×941px이며, 오브젝트 파일에는 투명 여백을 포함합니다.

- 야자수 2종
- 해안 바위 3종
- 해안 풀·수풀·해초 각 1종
- 부채 조개·소라 껍데기·불가사리 각 1종
- 산호 2종
- 해변 통나무·작은 나무배 각 1종

배경은 하늘·먼 지형·연속된 모래사장과 물결만 포함합니다. 배치할 가까운 야자수·바위·소품은 따로 제작하며 합성 시트에서 잘라내지 않습니다. 각 에셋의 원본 크기·알파 범위·투명 비율·visibleBounds·권장 anchor·SHA256은 manifest.json에 기록합니다.

[바다 배치 편집기](https://blaxarena.github.io/pokestudy/editor/?theme=sea)에서 직접 배치한 뒤 sea-layout.json을 저장할 수 있습니다. 숲속의 자동 저장과 별도로 저장됩니다. 현재 이 패키지는 배경과 에셋 편집 단계이며, 배치 후 내보낸 JSON을 바다 숨은그림찾기에 연결하는 작업은 별도입니다.
