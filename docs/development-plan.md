# 분석 및 개발 계획

## 기준과 보존 범위
입력: v10 HTML, 개발 의뢰서 1.0, 레이어 자산 규격 1.0, 투명 PNG ZIP.
v7 안정 버전과 별도 화풍 참고 파일은 제공되지 않아 비교하지 않았다.

v10은 빌드 없는 HTML이며 세 개의 스크립트 블록으로 구성된다.
- 이름 맞히기: 1~9세대 다중 선택, 문제 수, 정답+다른 종 2개+유사 오기, 3초 공개, TTS, 결과와 오답 재학습, 진행 표시 오른쪽 종료 버튼.
- 색칠: 세대 목록/검색, 원본, 자동 윤곽선, 펜/지우개/되돌리기, 팔레트/스포이드, PNG 저장.
- 이름 쓰기: 세대/문제 수, 큰 안내 글자, 펜/지우개/되돌리기, 저장.
- 숨은그림: 7테마, 3난이도, PokéAPI 1~9세대 후보, 한국어 이름, 목표 목록, 터치, TTS, 정답, 재시작.

앞 두 스크립트 블록을 원본 그대로 보존했다. 전체 회귀 테스트를 완료했다는 의미는 아니다.
숨은그림찾기만 별도 ES 모듈로 분리했다. 나머지 테마의 기존 장식 표현과 선택 기능을 유지했다.

## 위험과 자산 감사
31개 PNG 모두 RGBA, 알파 최솟값 0/최댓값 255이다. 하지만 이는 시각 품질 보증이 아니다.
manifest에 모든 파일이 segmented-estimate/review_required로 기록되어 있다.
1536×1024 시트에서 GrabCut으로 추출했으며 배경 잔여물, 인접 요소, 잘린 경계가 있을 수 있다.
오브젝트 해상도는 108×109~555×391 수준이다. 네이티브 4K로 표시할 수 없다.
v10 배경은 3840×2160이지만 나무/바위/수풀이 합성되어 있다. 파일 크기가 4K라는 사실은 원본 디테일을 보증하지 않는다.
기존 foreground는 임시 추출이므로 새 엔진에서 사용하지 않는다.

## 구현 순서와 현재 결과
1. 분석: 위 기능 목록과 자산 제약 확인.
2. 기반: 외부 배경/PNG, scene.json, 장면/이미지 캐시와 실패 시 재시도.
3. 레이어: 배경→후면 나무→포켓몬→전면 오브젝트→정답 원. 각 오브젝트 id/asset/x/y/scale/zIndex/width, hidden 제어 지원.
4. 배치: 45개 명시 슬롯, 고유 종/슬롯, 난이도별 정확한 수, 정규화 위치, 크기 범위. 현재 슬롯은 엔진 검증용 규칙적 배치이며 최종 그림에 맞춘 자연스러운 슬롯은 후속 작업이다.
5. 판정: 화면 좌표를 캔버스 좌표로 변환, 최소 44 CSS px 판정, 겹치는 판정은 가장 가까운 목표 우선. 표시·진행 초기화, 실패 이미지로 게임 시작 방지, TTS 예외 격리.
6. 검증: Node 무작위 배치 및 좌표 테스트, HTTP Chromium fixture 통합 테스트. 실제 PokéAPI 차단과 테스트 결과 구분.
7. 미완료: 독립 배경 확보 및 아트 QA→최종 자산별 슬롯 재측정→실제 Safari/Android 펜·TTS·저장 검증→숲속 2~5장.

## 필요한 이미지
- scene-01의 오브젝트 없는 배경: 16:9, 가능하면 실제 3840×2160 원본. 하늘/원경/지면/물길/길은 완결되어야 하며 나무·바위·덤불을 제거해도 구멍이나 복제 패치가 없어야 한다.
- 같은 화풍/광원의 나무 줄기와 앞쪽 잎, 바위, 덤불, 꽃, 버섯, 통나무, 그루터기 독립 원본. 현재 PNG 31개는 경계와 인접 조각 검수/보정 또는 교체가 필요하다.
- 기존 v9/v10 체감 크기 및 화풍 비교에 필요한 v7 안정본/별도 참고 이미지는 선택적으로 추가 제공 가능하다.

현재 배경으로는 '모든 주요 가림 오브젝트 분리' 인수 기준이 충족되지 않는다. 시제품을 최종 아트 완료로 간주하지 않는다.

## 장면 밀도 및 알파 품질 수정

사용자 피드백에 따라 시트 추출 자산 47개 반복 배치를 전부 제거했다. 실제 투명 배경으로 새로 생성한 독립 수풀 하나를 알파/시각 검수한 후 시냇가와 전경의 세 지점에만 배치한다. 45개 은신 슬롯 중 이 세 지점만 foregroundObjectIds를 연결하며 나머지는 가림 없는 슬롯으로 유지한다. 전체 포켓몬/목표 수는 기존 난이도 규칙을 따른다. 기존 배경은 유지하므로 모든 자연물 분리 인수 기준은 여전히 미완료이다.

## 현재 확장 범위

사용자 지시에 따라 테마마다 우선 1장씩 준비한다. 첫 바다는 모래사장과 얕은 바다로 확정했으며, 배경 1장과 15개 투명 에셋을 배치 편집기에 제공한다. 숲속과 바다 배치는 별도 sceneId와 브라우저 저장 키를 사용한다. 바다의 최종 게임 연결은 사용자 배치 JSON을 받은 뒤 진행한다.

고래왕 섬 1장은 업로드된 75개 오브젝트 배치를 고정하여 바다 게임에 연결했습니다. 숲속과 같은 난이도별 은신 위치·알파 가림 보정·목표 찾기·정답 표시·다시 시작을 지원합니다.
