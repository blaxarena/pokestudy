# 검증 결과

2026-11-05, Node 24.22.1, Python 3.12, 시스템 Chromium 155, HTTP 서버.

- `npm test`: 9개 통과. 난이도별 100회(총 300회) 배치, 개수/목표 수/고유 슬롯/이탈/겹침, 중복 종 거부, 슬롯 연결, 화면별 좌표.
- `python tests/browser_smoke.py`: 외부 API와 이미지 요청을 fixture로 대체. 3840×2160 DPR1, 1180×820 DPR2, 768×1024 DPR2, 390×844 DPR3에서 세 난이도씩 총 12회 흐름. 목표 터치 완료, 목표 수, 정답 보기, 다시 시작 시 초기화, 학습 모듈 전환. 제품의 실제 이미지나 API 성공을 의미하지 않는다.
- 1180×820 회귀: 4지선다 4개, 종료 버튼 위치/종료, 3초 후 공개, 색칠 목록/팔레트/펜/PNG 다운로드, 이름쓰기 안내/펜/PNG 다운로드/다음 문제.
- 원본 v10의 첫 두 script 블록과 현재 블록은 동일함을 확인했다.
- 31개 제공 PNG 모두 RGBA 및 alpha extrema (0,255). 시각 검수에서 나무의 사각 배경 잔여물 확인. 최종 자산 인수 실패.
- 최초 숲속 장면이 참조하는 고유 배경/오브젝트 전송량 3,982,087 bytes. 디코딩된 해당 이미지+4K 캔버스 한 장 계산치 약 65.6 MiB. 브라우저/GPU/캐릭터 이미지는 제외한 계산치이며 프로세스 메모리 실측은 아님.
- 기존 캔버스 saturate/drop-shadow 필터가 4K에서 큰 지연을 발생시켜 제거. 수정 후 fixture 시작→전체 목표 터치→정답→재시작 흐름은 이 머신에서 약 0.7~1.8초(네트워크 제외). 기기 FPS 보증은 아님.
- 실서비스 요청: raw.githubusercontent.com 스프라이트 HTTP 200. pokeapi.co CONNECT 403(Domain forbidden): 라이브 PokéAPI 기능 검증 차단. 환경 설정 초안에 pokeapi.co 허용을 추가했으며 실제 적용/재시험은 남아 있다.

미검증: 실제 Safari/Android, 실제 펜/음성, 실서비스에서 1~9세대 전체 로드, 최종 아트/마스크 기반 가림 상한, 네이티브 4K 선명도. 사용자 설정 적용 후 라이브 API를 재검증해야 한다.
