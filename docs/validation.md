## GitHub Pages 경로 검증

`BASE_URL=http://127.0.0.1:8001/pokestudy/ python tests/browser_smoke.py`로 프로젝트 하위 경로를 재현했다. 12개 플레이 흐름과 학습 회귀 검사가 모두 통과했다. 단위 검사 9개도 통과했다. GitHub Pages 설정 API는 Forbidden을 반환해 원격 활성화/배포 성공은 확인하지 못했다. 저장소 Settings → Pages에서 GitHub Actions를 선택하고 배포 workflow를 실행해야 한다.

## 오브젝트 정리 검증

기존 47개 추가 레이어를 3개 수풀로 축소했다. 배경 잔여물이 확인된 시트 추출 PNG는 모두 활성 장면에서 제외했다. 새 fern_clean.png는 RGBA 1774×887, 알파 0~255 및 네 모서리 투명, 외곽 시각 확인을 통과했다. 마지막 전경 수풀은 화면 하단 이탈을 막도록 너비를 0.10으로 제한했다. 단위 검사 9개와 하위 경로의 12개 브라우저 플레이 흐름 및 기존 학습 모듈 회귀가 통과했다. 브라우저 테스트는 기존과 같이 fixture를 사용했다. 기존 합성 배경은 그대로 유지하며 전체 자연물 분리는 완료되지 않았다.

## 사용자 배치 기반 숨은 포켓몬 찾기

업로드한 forest-layout.json의 49개 객체를 사용한다. 원본 좌표·크기·순서·flipX·opacity·hidden 값이 모델 검증 후에도 동일함을 확인했다. 배경 합성은 편집기의 PNG 내보내기와 픽셀 단위로 일치했다. 작은 바위의 축소 결과에 영향을 주던 가림 마스크용 캔버스 축소를 제거하고, 원본 알파의 수치 샘플링으로 대체했다.

난이도별 24개 무충돌 배치 세트를 생성했다. 실행 시 실제 포켓몬 알파와 상단 영역을 측정해 과도한 가림이면 포켓몬의 깊이만 앞으로 조정한다. 사용자 오브젝트의 순서는 변하지 않는다. 가림 상한은 전체 22/32/42%, 상단 12/18/22%다. 상단 영역은 실제 불투명 그림 범위의 위쪽 38%를 뜻하며 의미론적인 얼굴 검출은 아니다.

Node 검사 28개와 Chromium의 4개 화면 크기×3난이도 플레이, 학습 모듈의 주요 회귀를 통과했다. 별도 브라우저 검사에서 배경 합성 일치, 원본 49개 레이어 순서와 실제 fixture 스프라이트의 가림 상한도 확인했다. 포켓몬 API와 스프라이트는 이 테스트에서 fixture를 사용했으며 실제 서비스 응답·TTS·iPad 실기기를 검증한 것은 아니다.
