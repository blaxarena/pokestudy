# 숲속 배치 편집기

사용 주소: https://blaxarena.github.io/pokestudy/editor/

1. 왼쪽 에셋을 누르면 배경 가운데에 추가됩니다. PC에서는 배경으로 끌어 놓을 수도 있습니다.
2. 그림의 에셋을 끌어 이동합니다. 투명한 빈 공간은 선택하지 않으며, 배치 목록에서 직접 선택할 수 있습니다.
3. 선택 테두리의 오른쪽 아래 모서리나 크기 슬라이더로 크기를 조절합니다. 앞뒤 순서·숨기기·좌우 뒤집기·진하기·복제·삭제는 선택한 에셋에 적용됩니다.
4. 배치 JSON을 저장하면 나중에 다시 불러와 수정할 수 있습니다. 완성 PNG는 배경과 보이는 에셋만 합성한 1672×941 이미지입니다.

자동 저장은 현재 브라우저의 로컬 저장소를 사용합니다. 브라우저 데이터를 지우거나 기기를 바꾸기 전에 JSON을 보관하세요. 최대 200개를 배치할 수 있으며 최근 60개 편집 작업을 되돌릴 수 있습니다. 파일을 불러오는 작업과 전체 비우기도 되돌릴 수 있습니다. 되돌리기 기록은 탭을 새로 열면 초기화됩니다.

편집 JSON은 `version:1`, `sceneId:forest-01`, 고정 캔버스 크기, 배경 id와 objects를 포함합니다. 각 객체는 assetId, id, x/y/width(정규화된 실제 보이는 영역 기준), zIndex, hidden, flipX, opacity를 저장합니다. visibleBounds를 사용하므로 이미지의 넓은 투명 여백은 배치 크기에 포함되지 않습니다. 사용자 파일에서 외부 이미지 주소를 읽지 않으며, 제공된 35개 에셋 id만 허용합니다. 현재 숨은그림찾기의 scene.json과는 별도 편집 포맷입니다.

검증: Node 모델 검사 9개와 기존 검사 9개 통과. Chromium에서 1600×1000 DPR1, 1180×820 DPR2, 390×844 DPR3의 추가/실제 포인터 이동/크기/뒤집기/레이어/숨기기/복제/삭제/되돌리기, JSON 다운로드와 재입력·잘못된 파일 거부·브라우저 복원, PNG 다운로드와 크기·선택 테두리 제외를 확인했습니다. 태블릿/폰 이동에는 실제 터치 이벤트를 사용했습니다. 실제 iPad Safari 실기기는 미검증입니다.
