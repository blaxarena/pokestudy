# Forest Scene 01 — 투명 PNG 분리 패키지

- 총 31개 PNG 오브젝트 파일, 실제 RGBA 알파 채널 포함
- `objects/`에 나무, 바위, 수풀, 풀, 꽃, 소품, 지면 장식 분류
- `manifest.json`에 이름, 경로, 원본 시트 좌표, 이미지 크기 기록
- `source/original_asset_sheet.png`는 참고 원본

## 품질 및 사용상 주의
원본은 1536×1024 한 장의 이미지로, 투명 배경처럼 보이는 부분도 실제로는 색이 채워져 있었습니다.
이번 파일은 GrabCut 기반으로 배경을 제거해 **실제 알파 채널을 가진 PNG**로 만든 1차 추출본입니다.
개별 오브젝트 경계의 배경 잔여물, 인접 요소 혼입, 가장자리 손실이 있을 수 있습니다.
게임에 쓰기 전에 개별 시각 검수와 필요한 수작업 보정을 권장합니다.
원본 자체가 4K로 제작된 것이 아니므로 4K 네이티브 자산으로 표기하지 않습니다.
배경과 오브젝트는 별도로 제작된 이미지이므로 픽셀 단위 원본 복원 관계가 아닙니다.
Codex에서는 manifest의 위치를 원본 시트 좌표로 간주하고, 게임 장면 좌표는 새로 지정하세요.

## 현재 사용 자산

시트 추출 오브젝트 31개는 배경 잔여물 때문에 현재 scene.json에서 모두 제외했습니다. fern_clean.png는 단일 식물로 새로 생성한 RGBA 자산입니다. 크기 1774×887, alpha 0~255, 모서리 투명 및 외곽 시각 검수 완료. 기존 배경의 세 지점에 작게 배치하며, 원경/배경까지 모두 독립 레이어로 완성되었다는 의미는 아닙니다.
