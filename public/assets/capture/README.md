# Capture ball artwork

`balls.png` is a transparent four-ball sprite sheet generated using the user's supplied visual reference (2026-11-10). Order: orange normal ball, blue/red super ball, yellow/charcoal hyper ball, purple/pink master ball. The capture UI selects each illustration with CSS background positioning. The reference's appearance replaces the previous CSS circles without changing throw physics, hit areas, rewards, or capture probabilities.
